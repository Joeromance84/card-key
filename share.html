Changing your details

The contact card above is built from a block near the bottom of this file. Edit the values, commit, and the code changes everywhere this page is open. The download buttons always reflect what is on screen, so there are no stale image files to keep in step.

Printing uses PNG deliberately. Browsers drop SVG out of print jobs without saying so, which is how a card ends up with an empty square where the code should be.
