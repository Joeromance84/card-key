5 · The code

   

Download everything gives you all four PNG sizes, the SVG, and the contact file in one go. 512 for email, 1024 for general use, 2048 for print, 4096 for signage.

The print sheet uses the PNG on purpose. Browsers routinely drop SVG images out of a print job without warning, which is how people end up with cards that have a blank square where the code should be. Keep the SVG for a designer or a sign shop.
